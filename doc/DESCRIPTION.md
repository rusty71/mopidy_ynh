Mopidy is a music server that plays your local music and the streaming services
you subscribe to, and keeps everything in one interface.

This package adds the Iris web interface, the Qobuz extension with the album
cache, and a 320 kbps MP3 Icecast stream at 44.1 kHz that Mopidy publishes
itself.

Install it together with the Icecast app, which serves the stream.
